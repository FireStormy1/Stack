# 🧱 Stack

A minimal, relaxing, and addictive **browser-based stacking game** built for desktop and mobile devices.

Time your moves, stack the blocks, and build as high as you can. The better your timing, the higher your tower.

---

## 🚀 Live Demo

👉 **https://stack-liard.vercel.app/**

---

## 📌 About the Project

**Stack** is a simple browser game inspired by classic arcade stacking mechanics.

A block continuously moves across the screen. Your goal is to stop it at the right moment and stack it on top of the previous block.

With every successful stack, the tower grows higher.

The game is intentionally designed around a **minimal, clean, and distraction-free experience**, making it easy to pick up and play while still being challenging to master.

### The goal is simple:

> **Stack as high as you can. 🎯**

## ⚡ How to Play

1. Open the game.
2. Start a new game.
3. Watch the block move across the stacking area.
4. Time your move carefully.
5. Place the block on top of the existing stack.
6. Continue stacking additional blocks.
7. Build your tower as high as possible.
8. Try to beat your high score.
9. If the block misses the stack, the game ends.
10. Restart and try again!

## ⚡ Getting Started

### Prerequisites

Make sure you have **Node.js** installed.

### 1. Clone the repository

```bash id="7n4b8m"
git clone https://github.com/FireStormy1/Stack.git
```

### 2. Navigate to the project

```bash id="1q7x4v"
cd Stack
```

### 3. Install dependencies

Using pnpm:

```bash id="0h7j5x"
pnpm install
```

Or using npm:

```bash id="3r9v2c"
npm install
```

### 4. Start the development server

```bash id="8m2k5p"
pnpm dev
```

Or:

```bash id="5t7x1q"
npm run dev
```

The application will be available at the local development URL provided by Vite.
